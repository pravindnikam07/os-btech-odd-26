## Topics covered

- OS concepts, generations, and types: batch, time-sharing, distributed, and real-time
- OS services and system calls: process, file, and device
- OS structures: layered, monolithic, microkernel, and hybrid
- Virtualization: Type 1 and Type 2 hypervisors (VMware, Xen, KVM, VirtualBox)
- Cloud OS: AWS EC2, Azure VMs, and GCE
- Mobile OS: Android (Linux kernel and HAL) and iOS (Darwin and Core OS)
